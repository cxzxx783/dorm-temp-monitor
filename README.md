# 宿舍温湿度管家 (Dorm Temp Monitor)

一个 Windows 桌面小软件，通过电脑自带蓝牙直读 **小米温湿度计 3 mini**（型号 `MJWSD06MMC`）的实时温湿度，自动记录并实时绘制温度/湿度曲线。

无需小米网关、无需米家云、数据不出本机。数据明文，免绑定。

![界面](docs/screenshot.png)

## 功能

- 🌡️ 实时温度 + 湿度双曲线（ECharts 深色主题）
- 📝 自动不间断记录，断线自动重连
- ⚡ 电池电压监控（电量不足有提示）
- ⚙️ 采样间隔可调：6s / 15s / 30s / 60s / 5min
- 📊 数据存 CSV（每日一个文件），可用 Excel 打开
- 💻 界面美观、双击 `.bat` 即用

## 快速开始

1. 需要：Windows 10/11、本机蓝牙、小米温湿度计 3 mini
2. 安装依赖：`pip install bleak pywebview`
3. 双击 `启动温湿度管家.bat`（或 `python app.py`）
4. **按一下温度计侧边按键**唤醒它的蓝牙
5. 状态灯变绿 = 开始采集

> 温度计平时处于省电休眠，所以每次软件启动后需要按一次按键，这是它的硬件设计。

## 数据文件

记录保存在 `data/temp_log_YYYY-MM-DD.csv`，格式：`时间,温度℃,湿度%,电压V`

## 工作原理

- 蓝牙扫描识别设备名 `MJWSD06MMC`（小米 MiBeacon 协议）
- 连接后订阅通知 + 定时主动读取特征 `ebe0ccc1-7a0a-4b0c-8a1a-6ff2997da3a6`
- 数据 5 字节小端：温度(2字节 ÷100) + 湿度(1字节) + 电压(2字节 ÷1000)

## 项目结构

```
app.py       主程序(pywebview 窗口 + 前后端桥接)
sensor.py    蓝牙采集核心(独立线程, 自动重连)
index.html   界面(ECharts 折线图)
assets/      echarts.min.js
data/        记录输出目录
```

## 兼容性

- 同型号温湿度计（`MJWSD06MMC`）直接可用
- 其他小米温湿度计型号：改 `app.py` 中 `DEVICE_NAME` 即可（数据特征可能不同，需对照实测）
- 纯本地运行，**不连接任何云端服务器**
